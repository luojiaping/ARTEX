# FOFA 常见坑与误报

> 这份文件只记「会让人做错判断」的坑，不重复语法。语法见 `query-syntax.md`。

## 1. 范围与合规

- **FOFA 是全互联网索引**：能查到不等于能测。任务范围外的资产只做「记录/汇报」，不要发起任何探测。
- **不要用大范围模糊词裸查**：`body="admin"`、`title="login"` 这类查询结果上百万，既烧额度又没有行动价值。
- **不要查与任务无关的敏感数据**：泄露库、个人信息、他人业务数据不在资产侦察范围内。

## 2. 结果可信度

| 坑 | 表现 | 处置 |
|---|---|---|
| 快照过期 | FOFA 显示 200，实际已下线/换站 | 用 curl/httpx 探活后再入库 |
| CDN/WAF 混淆 | 同一 `ip` 对应成百上千域名 | 用 `cname`、`cert`、`header` 交叉判断；别把 CDN IP 当目标资产 |
| 泛解析/默认页 | `title="Index of /"` 命中大量默认页 | 加 `body`/`header` 第二特征；人工看前 50 条 |
| 蜜罐/扫描器 | 结果像目标但行为异常 | 观察 banner/证书/响应时间；不确定就标 `inferred` |
| 标题重复 | 模板站标题完全相同 | 用 `icon_hash`/`fid`/`body_hash` 聚类，避免把模板站当成同一实体 |

## 3. 查询语法坑

- `=` 是**包含**匹配，`==` 才是精确匹配；`*=` 是模糊搜索，不是「等于通配符」。
- `*` 匹配任意长度，`?` 只匹配一个字符；`host*="test*.baidu.com"` 与 `host="test.baidu.com"` 语义不同。
- `&&` 优先级高于 `||`，混用必须加括号。
- 值里含双引号时，外层用单引号：`header='X: "abc"'`。
- `type="service"` 是协议服务（不含 HTML），`type="subdomain"` 是网站；查目录页时忘了这个会漏/多。
- `body` 查询很贵（大字段），能用 `title`/`header`/`server` 就不用 `body`。

## 4. 额度与翻页

- **`remain_api_query` 和 `remain_api_data` 是两套额度**：翻页扣查询次数，返回行数扣数据量。
- `search/all` 是 from/size 深翻页：页码越深越慢，超过约 1 万条容易被限制或错页。
- `search/next` 是游标：不能随机跳页；游标只对同一 query 有效；结果为空或 `next` 缺失即结束。
- **`full=false` 只查近一年**；需要历史数据时显式 `full=true`，否则会误以为「没有结果」。
- `size=10000` 不等于应该传 10000；带 `banner`/`body`/`cert` 时响应会非常大。
- 工具侧有全局限流（默认 1.5 次/秒）；多 worker 并发会排队，不要以为卡住了就重复调用。

## 5. 错误码误判

- `error=true` 经常是 **HTTP 200**，必须解析响应体，不能只看状态码。
- `code` 可能缺失，需要从 `errmsg` 的 `[-700]` 这类前缀提取。
- `-5`/429 可重试；`-700`/`-4`/`-1`/`820000` 不要重试（重试只会继续失败/烧额度）。
- `-403 访问权限不足` 表示账号没开通该接口（常见于 `stats`/`host`），不是 key 失效；改用 `search`。
- `820000` 表示账号没开通连续翻页，不是语法错误；改用 `mode=page`。

## 6. 资产入库坑

- `ip` 字段只能填纯 IP；把 `host:port` 塞进 `ip` 会污染资产图。
- `host` 是 `host:port` 形式，不是完整 URL；完整 URL 用 `link`。
- `status_code`/`content_length`/`technologies` 必须是**自己探测确认过**的，不要从 FOFA 抄。
- 同一资产可能被多个 FOFA 字段命中；入库前按 `ip:port` / `domain` 去重。
- FOFA 的 `icon_hash` 是 favicon mmh3 的**有符号**表示；填 `favicon_mmh3` 时保持一致。

## 7. 成本控制清单（开查前自检）

1. 这个 query 有明确的目的吗？
2. 先用 `fofa_stats` 看过规模了吗？
3. `size` 是不是按规模选的，而不是默认最大值？
4. 需要 `body`/`banner`/`cert` 吗，还是 `title`/`header` 就够？
5. 这批结果准备怎么验证、怎么入库、怎么去重？
6. 额度还够吗（`fofa_account`）？
